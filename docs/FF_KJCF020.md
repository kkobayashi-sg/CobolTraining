各添字に格納される値の意味は以下のとおりです。

| 値  | 意味       |
| :-: | ---------- |
| △   | エラーなし |
| 1   | 形式エラー |
| 2   | マスタなし |

凡例:

| 記号           | 説明 |
| -------------- | ---- |
| **X(n)**       | 英数字 n桁 |
| **N(n)**       | 日本語 n文字 |
| **9(n)**       | ゾーン形式10進数（整数部 n桁） |
| **V9(m)**      | 小数部 m桁（`V`は小数点の位置を表し、領域は取りません） |
| **S**          | 符号付き |
| **PACKED-DECIMAL** | パック形式10進数 |
| **△**          | 半角スペース |

> 例: `S9(5)V9(2)` は「符号付き・整数部5桁・小数部2桁」を表します。
