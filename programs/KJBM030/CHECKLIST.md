# KJBM030 単体テストチェックリスト

## 正常系：マッチング(ITF=IMF)
- [x] マッチした際、出力ファイル(OTF)に商品マスタの商品名・単価が正しくセットされているか
- [x] エラー区分(6)がSPACEのとき、「数量×単価」が正しく計算され、OTFの金額欄にセットされているか
- [x] エラー区分(6)がSPACE以外の時、金額に「0」がセットされているか
- [x] 同じ商品番号の注文が複数連続した場合、その全てに対して正しくマスタの情報がセットされるか

## 異常系：アンマッチ(ITF < IMF または マスタ終了)
- [x] マスタに存在しない商品番号の場合、エラー区分(5)に'2'がセットされているか
- [x] マスタ不一致の際、商品名・単価・金額は（計算できないため）初期状態または元の値を維持しているか
- [x] 商品マスタが先に全件読み終わった後、残りの受注データ全てに対して正しくエラー'2'がセットされるか

## 除外条件：既エラーレコードの処理
- [x] 入力時点でエラー区分(5)に値('1'など)が入っているレコードは、たとえマスタに存在する商品番号であっても、マスタ情報のセット（名前・単価・金額計算）が行われず、そのまま出力されるか
- [x] 既エラーレコードのエラー区分(5)の内容が、別の値('2'など)で上書きされずに保持されているか

## マッチング制御(ITF > IMF)
- [x] 受注データの商品番号よりも小さい番号のマスタデータが存在する場合、そのマスタを読み飛ばして正しい位置で照合が開始されるか

## ファイル統計・共通事項
- [x] 実行後のDISPLAYメッセージで、ITF(入力)・IMF(マスタ)・OTF(出力)の各件数がテストデータの件数と一致しているか
- [x] プログラムがRETURN-CODE = 0　で正常終了しているか
- [x] 出力ファイル(OTF)の全レコードにおいて、商品番号や受注日などの基本項目が、入力データから崩れずに引き継がれているか
