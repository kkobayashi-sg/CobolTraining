# KJBM050 単体テストチェックリスト

## 確認内容の概要

受注チェックファイル（ITF）を読み込み、エラー区分テーブルの状態に基づいて
正常分ファイル（OTF1）とエラー分ファイル（OTF2）のどちらか一方へ振り分けること。

## テスト項目

### 1. 振り分け処理

#### 正常分への振り分け（OTF1）

- [ ] (1) エラー区分テーブルが全てスペースのレコードが OTF1（正常分）へ出力されること
- [ ] (2) 正常分レコードの内容が変更されずにそのまま転送されること

#### エラー分への振り分け（OTF2）

- [ ] (3) エラー区分テーブルのいずれかがスペース以外のレコードが OTF2（エラー分）へ出力されること
- [ ] (4) エラー分レコードの内容が変更されずにそのまま転送されること
- [ ] (5) エラー区分テーブルの複数のフラグがセットされているレコードも OTF2 へ出力されること

### 2. 処理全体の確認

- [ ] (1) 実行開始時に「*** KJBM050 START ***」が表示されること
- [ ] (2) 実行終了時に「*** KJBM050 END ***」が表示されること
- [ ] (3) ITF-CNT・OTF1-CNT・OTF2-CNT が正しく表示され、ITF = OTF1 + OTF2 となること

### 3. 異常系

- [ ] (1) 入力ファイルが空の場合、正常に終了し件数が全て0件と表示されること
- [ ] (2) 入力ファイルが存在しない場合、ABEND メッセージが表示されプログラムが異常終了すること
