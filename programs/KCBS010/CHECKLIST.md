# KCBS010 単体テストチェックリスト

## 正常系
- [x] 入力された西暦日付が6桁のときは、年上2桁に00が転記されて8桁に変換される
- [x] 入力された西暦日付の年、月、日すべてが反映されている
- [x] 入力された西暦日付にて月が02なら、最大日数nが29となる
- [x] 入力された西暦日付にて月が04なら、最大日数nが30となる
- [x] 入力された西暦日付にて月が06なら、最大日数nが30となる
- [x] 入力された西暦日付にて月が09なら、最大日数nが30となる
- [x] 入力された西暦日付にて月が11なら、最大日数nが30となる
- [x] 入力された西暦日付にて月が02,04,06,09,11以外なら、最大日数nが31となる
- [x] 入力された西暦日付にて月が04,06,09,11なら、最大日数nが30となる
- [x] 西暦日付の年上2桁がゼロでかつ年下2桁が90未満なら、年上2桁に20をセットする
- [x] 西暦日付の年上2桁がゼロでかつ年下2桁が90以上なら、年上2桁に19をセットする

## 異常系(復帰コードに'E'がセットされる)
- [x] 入力された西暦日付に数字以外が含まれていると、復帰コードに'E'がセットされる
- [x] 月に1から12以外の数字が含まれると、復帰コードに'E'がセットされる
- [x] 日に1からn(各月の最大日数)以外の数字が含まれると、復帰コードに'E'がセットされる
- [x] 年が閏年でなく、かつ月日が2月29日なら、復帰コードに'E'がセットされる
